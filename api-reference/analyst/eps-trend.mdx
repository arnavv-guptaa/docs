---
title: 'EPS Trend'
openapi: 'GET /v1/eps-trend'
---

Get how the consensus EPS estimate for a symbol has moved over the last 7, 30, 60, and 90 days, by forecast period.

## Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `symbol` | string | Yes | Stock symbol (e.g., `AAPL`, `MSFT`) |

## Response

Returns a dictionary keyed by snapshot age, with each value itself a dictionary keyed by forecast period (`0q` current quarter, `+1q` next quarter, `0y` current fiscal year, `+1y` next fiscal year):

```json
{
  "current": { "0q": 1.65, "+1q": 1.82, "0y": 7.1, "+1y": 7.9 },
  "7daysAgo": { "0q": 1.65, "+1q": 1.82, "0y": 7.08, "+1y": 7.88 },
  "30daysAgo": { "0q": 1.64, "+1q": 1.8, "0y": 7.05, "+1y": 7.85 },
  "60daysAgo": { "0q": 1.62, "+1q": 1.78, "0y": 7.0, "+1y": 7.8 },
  "90daysAgo": { "0q": 1.6, "+1q": 1.75, "0y": 6.95, "+1y": 7.75 }
}
```

Returns `null` when no EPS trend data is found for the symbol.

## Example

```bash
curl "https://api.chicago.global/v1/eps-trend?symbol=AAPL" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
