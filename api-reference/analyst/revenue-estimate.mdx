---
title: 'Revenue Estimate'
openapi: 'GET /v1/revenue-estimate'
---

Get consensus revenue estimates for a symbol across the current and next fiscal quarter and year.

## Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `symbol` | string | Yes | Stock symbol (e.g., `AAPL`, `MSFT`) |

## Response

Returns a dictionary keyed by field name, with each field itself a dictionary keyed by forecast period (`0q` current quarter, `+1q` next quarter, `0y` current fiscal year, `+1y` next fiscal year). Revenue figures are in the reporting currency's base units:

```json
{
  "avg": { "0q": 94500000000, "+1q": 131200000000, "0y": 405300000000, "+1y": 438900000000 },
  "low": { "0q": 92100000000, "+1q": 127800000000, "0y": 398700000000, "+1y": 425100000000 },
  "high": { "0q": 97800000000, "+1q": 136500000000, "0y": 412900000000, "+1y": 452300000000 },
  "numberOfAnalysts": { "0q": 21, "+1q": 19, "0y": 27, "+1y": 24 },
  "yearAgoRevenue": { "0q": 89500000000, "+1q": 119600000000, "0y": 391000000000, "+1y": 405300000000 },
  "growth": { "0q": 0.0559, "+1q": 0.0971, "0y": 0.0362, "+1y": 0.0828 }
}
```

Missing or non-finite provider values come back as `null` rather than `NaN`. Returns `null` when no estimate data is found for the symbol.

## Example

```bash
curl "https://api.chicago.global/v1/revenue-estimate?symbol=AAPL" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
