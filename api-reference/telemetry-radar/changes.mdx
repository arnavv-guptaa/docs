---
title: 'Telemetry Changes'
openapi: 'GET /v1/telemetry/changes'
---

Part of the **telemetry-radar** layer, a newer set of endpoints built on the
daily basket signal log. It is separate from the baskets under
[Telemetry](/api-reference/telemetry/summary), which read the daily telemetry
row directly.

What changed in the telemetry baskets over a lookback window: quadrant
changes, new divergences (fatigue or rebound), themes confirmed in more
markets, and moves of 3 or more standard deviations. Each event carries the
basket's current quadrant and momentum for context.

<Note>
Built from the daily signal log. From 2026-09-25 each day's signals are
recorded as seen that day, with no hindsight. Earlier dates come from a later
backfill run. Only active baskets are reported.
</Note>

## Query Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `days` | integer | No | `7` | Look back this many calendar days from the latest report. Range 1–90. |
| `market` | string | No | — | Market code or country name to narrow to, e.g. `JP` or `Japan`. |
| `types` | array of string | No | All types | Event types to include. Repeat the parameter for several. Valid values: `quadrant_change`, `divergence`, `theme_spreading`, `big_move`. |
| `limit` | integer | No | `50` | Maximum events returned, newest first. Range 1–500. |

An unknown value in `types` returns `400`.

## Response

The window, counts per event type, and the events themselves (newest first,
capped at `limit`). A `note` field appears only when more events matched than
`limit` allows. `legend` explains each event type and is static.
