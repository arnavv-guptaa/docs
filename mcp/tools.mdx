The Parallax MCP server exposes the 35 tools below. Each call is billed in **credits** from
your organization's balance, at the cost listed for that tool. The same cost appears in each
tool's description, so your assistant can see it before it makes a call. Tools listed at 0
credits are free. Check your balance in the Console under **Settings → API Console**.
Tools marked **async** use background jobs. The MCP server normally waits for the result
by polling internally. Call `check_job_status` only when a tool returns a `job_id`
without a completed result. Most jobs complete in seconds to a few minutes.

Recommendation labels (`STRONG BUY` to `STRONG SELL`) and sell-side analyst recommendations
are returned only when the connected account's organization is
[KYC-verified](/problems/kyc-required). Other accounts get the same factor scores without the
label, and a tool that returns only recommendation data answers with a `kyc_required` error.

<Note>
Symbols use **RIC** format (e.g. `AAPL.O`, `JPM.N`, `2330.TW`). Use `search_stocks` /
`search_etfs` to resolve a symbol first if you're unsure.
</Note>

## Stocks & scores

| Tool | What it does | Credits | Timing |
|------|--------------|------|--------|
| `search_stocks` | Find a stock by symbol, name, sector, or industry (typo-tolerant). Use before other tools to get the RIC. | 1 | Instant |
| `get_company_info` | Company profile: sector, industry, market cap, description. Accepts comma-separated multi-symbol. | 1 | Instant |
| `get_peer_snapshot` | Score a stock against its peers — the default "tell me about X" tool. Returns Quality/Value/Momentum/Defensive/Tactical plus a peer comparison. | 1 | Fast |
| `get_score_analysis` | Historical factor-score trends (how Quality/Value/Momentum/Defensive/Tactical evolved). | 1 | Instant |
| `get_score_summary` | Plain-language summary of where a stock's factor scores stand over the past 52 weeks: current score and 13-week trend. | 1 | Instant |
| `get_performance_history` | Past price performance: year-to-date, last 12 months, average yearly return, best and worst month and year, and a month-by-month returns calendar. | 2 | Instant |
| `get_financials` | Financial statements & ratios — `statement`: `income`, `balance_sheet`, `cash_flow`, `ratios`, `summary`. | 1 (2 with `latest=true` on a statement) | Instant |
| `get_stock_outlook` | Analyst outlook — `aspect`: `analyst_targets`, `recommendations`, `risk_return`, `dividends`. The `recommendations` aspect requires a [KYC-verified organization](/problems/kyc-required). | 1 | Instant |
| `get_technical_analysis` | Trend, momentum (RSI, MACD), support/resistance, volume, volatility. | 5 | Async (~15–30s) |
| `get_financial_analysis` | Deep financial analysis using Palepu's framework (profitability, liquidity, solvency, valuation). | 5 | Async (~2–5m) |
| `get_stock_report` | Full Chicago Global research report with PDF/HTML links. | 10 | Async (~1–2m) |
| `export_price_series` | Price data for charting tools (dates/prices, CSV, or JSON). | 1 | Instant |
| `export_peer_comparison` | Peer-comparison data for charting tools. | 1 | Instant |

## Utility

| Tool | What it does | Credits | Timing |
|------|--------------|------|--------|
| `check_api_health` | Check that the Parallax API is reachable and healthy. | 0 | Instant |
| `check_job_status` | Check a background job (`pending` / `processing` / `completed` / `failed`) and retrieve results. | 0 | Instant |
| `submit_feedback` | Send feedback or report an issue to Chicago Global (auto-classified by priority). | 0 | Instant |

<Tip>
MCP tools normally return the completed result after polling internally. If a tool
returns only a `job_id`, pass that exact ID to `check_job_status`. Stop when the job
reports `completed` or `failed`. The [REST API](/api-reference/jobs/status) exposes job
submission and polling as separate requests.
</Tip>
