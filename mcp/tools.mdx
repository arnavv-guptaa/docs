The Parallax MCP server exposes the 35 tools below. Calls use your organization's
credit balance at the underlying API prices listed here. Credits can be fractional,
and a tool that makes several API calls adds their costs. Tools listed at 0 credits
are free. Check your balance in the Console under **Settings → API Console**.

<Note>
Some MCP tool descriptions still quote older prices. The API bills the current
prices below. See [API credits](/api-reference/introduction#credits) for billing
behavior and fractional balances.
</Note>
Tools marked **async** use background jobs. The MCP server normally waits for the result
by polling internally. Call `check_job_status` only when a tool returns a `job_id`
without a completed result. Most jobs complete in seconds to a few minutes.

<Note>
Symbols use **RIC** format (e.g. `AAPL.O`, `JPM.N`, `2330.TW`). Use `search_stocks` /
`search_etfs` to resolve a symbol first if you're unsure.
</Note>

## Stocks & scores

| Tool | What it does | Credits | Timing |
|------|--------------|------|--------|
| `search_stocks` | Find a stock by symbol, name, sector, or industry (typo-tolerant). Use before other tools to get the RIC. | 0 | Instant |
| `get_company_info` | Company profile: sector, industry, market cap, description. Accepts comma-separated multi-symbol. | 0.05 per symbol | Instant |
| `get_peer_snapshot` | Score a stock against its peers. Returns Quality/Value/Momentum/Defensive/Tactical plus a peer comparison. | 0.1 | Fast |
| `get_score_analysis` | Historical factor-score trends (how Quality/Value/Momentum/Defensive/Tactical evolved). | 0.1 | Instant |
| `get_score_summary` | Plain-language summary of where a stock's factor scores stand over the past 52 weeks: current score and 13-week trend. | 0.1 | Instant |
| `get_performance_history` | Past price performance, a returns calendar, and risk/return versus peers. Makes two analytics calls. | 0.2 | Instant |
| `get_financials` | Financial statements and ratios. `statement`: `income`, `balance_sheet`, `cash_flow`, `ratios`, `summary`. | 0.05 per symbol; 0.1 with `latest=true` for income, balance sheet, or cash flow | Instant |
| `get_stock_outlook` | Analyst outlook. `aspect`: `analyst_targets`, `recommendations`, `risk_return`, `dividends`. | 0.05; 0.1 for `risk_return` | Instant |
| `get_technical_analysis` | Trend, momentum (RSI, MACD), support/resistance, volume, volatility. | 5 | Async (~15–30s) |
| `get_financial_analysis` | Deep financial analysis using Palepu's framework (profitability, liquidity, solvency, valuation). | 5 | Async (~2–5m) |
| `get_stock_report` | Full Chicago Global research report with PDF/HTML links. | 10 | Async (~1–2m) |
| `export_price_series` | Price data for charting tools (dates/prices, CSV, or JSON). | 0.05 | Instant |
| `export_peer_comparison` | Peer-comparison data for charting tools. | 0.1 | Instant |

## Macro & market telemetry

| Tool | What it does | Credits | Timing |
|------|--------------|------|--------|
| `macro_analyst` | Macro outlook for a market or country, with overview and component views. | 5 normally; up to 50 during overview recovery | ~2–3s |
| `list_macro_countries` | List all markets/countries with available macro reports. | 0 | Instant |
| `check_macro_health` | Deprecated macro-market-list check. Use `check_api_health` for API health. | 0 | Instant |
| `get_telemetry` | Daily market telemetry snapshot, regime, leading/lagging baskets, and narrative. Returns directly without job polling. | 0.05 | Synchronous |

If a macro overview fails, `macro_analyst` can make nine additional report requests.
Each successful HTTP response costs 5 credits, including HTTP `200` responses whose
body reports a failure. HTTP errors do not deduct credits, and market-list lookups
are free. An explicit component request does not trigger the nine-request recovery.

## Utility

| Tool | What it does | Credits | Timing |
|------|--------------|------|--------|
| `check_api_health` | Check that the Parallax API is reachable and healthy. | 0 | Instant |
| `check_job_status` | Check a background job (`pending` / `processing` / `completed` / `failed`) and retrieve results. | 0 | Instant |
| `submit_feedback` | Send feedback or report an issue to Chicago Global (auto-classified by priority). | 0 | Instant |

<Tip>
MCP tools normally return the completed result after polling internally. If a tool
returns only a `job_id`, pass that exact ID to `check_job_status`. Stop when the job
reports `completed` or `failed`. The [REST API](/api-reference/jobs/status) exposes job
submission and polling as separate requests.
</Tip>
